Guía de Instalación y Ejecución
Módulo Web y Consola (PC)

Abrir una terminal de comandos e ingresar a la carpeta Web-Consola.

Instalar las dependencias requeridas de Python ejecutando: pip install flask opencv-python.

Para ejecutar la vista local de la cámara, ingresar el comando: python consola.py.

Para inicializar el servidor web de streaming, ejecutar: python app.py y abrir en cualquier navegador web la dirección local que indique la terminal

Para compilar el proyecto en formato de aplicación nativa, se requiere tener instalado el SDK de Flutter y Android Studio.

Conectar un dispositivo móvil Android a la computadora por cable USB con el "Modo de Depuración USB" habilitado.

Abrir una terminal e ingresar a la carpeta raíz del proyecto móvil: cd escaner_aves.

Descargar y sincronizar los paquetes de la aplicación ejecutando: flutter pub get.

Compilar, instalar y lanzar la aplicación directamente en el celular ejecutando: flutter run.
